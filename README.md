# 🤖 ربات تلگرام فروش فیلترشکن (VPN Shop Bot)

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)
![aiogram](https://img.shields.io/badge/aiogram-3.x-2CA5E0?logo=telegram&logoColor=white)
![SQLite](https://img.shields.io/badge/Database-SQLite-003B57?logo=sqlite&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

ربات کامل و آماده فروش سرویس‌های V2Ray (VLESS / VMess / Trojan / Reality) در تلگرام، نوشته‌شده با **Python** و **aiogram 3**.
تمام اطلاعات (کاربران، سفارش‌ها، پلن‌ها، کانفیگ‌ها و تنظیمات) فقط روی **سرور خودتان** و در یک فایل **SQLite** ذخیره می‌شود و به هیچ دیتابیس یا سرویس خارجی نیاز ندارد.

## ✨ امکانات

### 👤 بخش کاربران
- 🛒 **خرید سرویس**: انتخاب لوکیشن و پلن (روزانه، هفتگی، ماهانه، سه‌ماهه و هر مدت دلخواه)
- 💳 **پرداخت** کارت‌به‌کارت یا لینک پرداخت و ارسال رسید (عکس، فایل یا کد پیگیری)
- ⚡️ **تحویل خودکار** کانفیگ پس از تایید ادمین، همراه با لینک ساب‌اسکریپشن و **QR کد**
- 📦 **سرویس‌های من**: وضعیت، زمان باقی‌مانده و **حجم مصرفی** (دریافت زنده از پنل)
- 🔄 **تمدید سرویس** (روزها به تاریخ انقضای فعلی اضافه و حجم مصرفی صفر می‌شود)
- ⏰ **یادآوری خودکار** ۲۴ ساعت قبل از انقضا و اطلاع‌رسانی پس از انقضا
- 🎧 **پشتیبانی و تیکت** با امکان ارسال عکس و پیگیری تاریخچه
- 👤 حساب کاربری و سوابق سفارش‌ها + راهنمای اتصال

### ⚙️ پنل مدیریت (فقط برای آیدی عددی مالک)
- 📦 افزودن، ویرایش، فعال/غیرفعال و حذف **پلن‌ها**
- 🖥 مدیریت **سرورها** با سه روش تحویل کانفیگ:
  - 📝 **دستی**: انبار کانفیگ‌های آماده (هر خط یک کانفیگ یا فایل txt)
  - 🟦 **3x-ui (سنایی)**: ساخت خودکار کاربر — نسخه‌های ۲.x و ۳.x (تشخیص خودکار)
  - 🟪 **Marzban / PasarGuard**: ساخت خودکار کاربر
- 👥 **مدیریت کاربران**: جستجو (آیدی، یوزرنیم یا فوروارد پیام)، مسدودسازی، افزایش/کاهش روز، لغو سرویس، سرویس هدیه، پیام خصوصی
- 🧾 **بررسی سفارش‌ها**: تایید یا رد (با دلیل) — در صورت خطای پنل: تلاش مجدد یا ارسال دستی کانفیگ
- 📊 **آمار** کاربران، فروش روزانه/هفتگی/ماهانه و پرفروش‌ترین پلن‌ها
- 📣 **پیام همگانی** (همه کاربران یا فقط دارندگان سرویس فعال)
- 💳 **تنظیمات درگاه**: کارت‌به‌کارت و لینک پرداخت
- ✏️ ویرایش متن خوش‌آمد، پشتیبانی و راهنما از داخل ربات
- 💾 **بکاپ خودکار روزانه ساعت ۰۰:۰۰** و ارسال فایل برای ادمین + **ریستور** با ارسال فایل بکاپ

### 🧱 فنی
- دیتابیس SQLite با حالت WAL، تراکنش‌های اتمی و سیستم مهاجرت خودکار ساختار
- جلوگیری از تایید دوباره سفارش و فروش دوباره یک کانفیگ (عملیات اتمی)
- لاگ کامل در `logs/bot.log` (چرخشی) و journald، مدیریت سراسری خطاها
- سرویس systemd با اجرای خودکار پس از ری‌استارت سرور یا بروز خطا
- پشتیبانی از پروکسی (SOCKS5/HTTP) برای سرورهایی که به تلگرام دسترسی ندارند
- تست‌های خودکار (سناریوهای کامل خرید، پنل‌های ساختگی، بکاپ و ...)

## 📋 پیش‌نیازها

| مورد | توضیح |
|---|---|
| سرور | یک VPS با **Ubuntu 22.04 / 24.04** یا Debian 12 (حداقل 512MB رم کافی است) |
| دسترسی | دسترسی root یا کاربر دارای sudo |
| اینترنت | سرور باید به `api.telegram.org` دسترسی داشته باشد (سرورهای خارج از ایران). برای سرور ایران [پروکسی](#-تنظیمات-فایل-env) لازم است |
| توکن ربات | از ربات [@BotFather](https://t.me/BotFather) |
| آیدی عددی | آیدی عددی تلگرام خودتان از ربات [@userinfobot](https://t.me/userinfobot) |

**دریافت توکن ربات:**
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید و دستور `/newbot` را بفرستید.
2. یک نام و سپس یک یوزرنیم (که به `bot` ختم شود) برای ربات انتخاب کنید.
3. توکنی شبیه `123456789:AAH...` دریافت می‌کنید؛ آن را نگه دارید.

**دریافت آیدی عددی:** به [@userinfobot](https://t.me/userinfobot) پیام دهید؛ عددی مثل `123456789` برمی‌گرداند.

> ⚠️ قبل از نصب، حتماً یک بار به ربات خودتان `/start` بدهید تا ربات بتواند برای شما پیام (و فایل بکاپ) بفرستد.

## 🚀 نصب سریع (پیشنهادی)

با SSH به سرور وصل شوید و دستورات زیر را به ترتیب اجرا کنید:

```bash
sudo apt update && sudo apt install -y git
sudo git clone https://github.com/HOTKYNTAKY/1387eiman.git /opt/vpn-bot
cd /opt/vpn-bot
sudo bash scripts/install.sh
```

اسکریپت نصب به صورت خودکار:
1. پیش‌نیازها (Python 3.10+، venv، git) را نصب می‌کند (در Ubuntu 20.04، پایتون 3.11 نصب می‌شود)
2. محیط مجازی `.venv` را می‌سازد و کتابخانه‌ها را نصب می‌کند
3. **توکن ربات** و **آیدی عددی ادمین** را از شما می‌پرسد و در فایل `.env` ذخیره می‌کند
4. سرویس systemd با نام `vpn-bot` را می‌سازد و ربات را اجرا می‌کند

نمونه سؤال‌های نصب:

```text
1) Bot token from @BotFather  |  توکن ربات را از @BotFather بگیرید
🔑 BOT_TOKEN: 123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsawQ
   ✅ Token is valid / توکن معتبر است  →  @MyVpnShopBot

2) Your numeric Telegram ID (get it from @userinfobot)
👤 ADMIN_ID: 123456789
✅ Settings saved to /opt/vpn-bot/.env
```

✅ تمام! حالا در تلگرام به ربات `/start` بدهید؛ دکمه **«⚙️ پنل مدیریت»** فقط برای شما نمایش داده می‌شود.

## 🛠 نصب دستی مرحله‌به‌مرحله

اگر می‌خواهید همه مراحل را خودتان انجام دهید:

**۱. نصب پیش‌نیازها**
```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip git
python3 --version   # باید 3.10 یا بالاتر باشد
```

**۲. دریافت پروژه**
```bash
sudo git clone https://github.com/HOTKYNTAKY/1387eiman.git /opt/vpn-bot
cd /opt/vpn-bot
```

**۳. ساخت محیط مجازی و نصب کتابخانه‌ها**
```bash
sudo python3 -m venv .venv
sudo .venv/bin/pip install -r requirements.txt
```

**۴. اجرای اولیه و تنظیم توکن و آیدی ادمین**
```bash
sudo .venv/bin/python -m bot
```
در اولین اجرا، ربات توکن و آیدی عددی را می‌پرسد و در `.env` ذخیره می‌کند، سپس اجرا می‌شود.
پس از دیدن پیام `Bot @... started` با `Ctrl + C` آن را متوقف کنید.
(برای تغییر توکن یا ادمین در آینده: `sudo .venv/bin/python -m bot --setup`)

**۵. نصب سرویس systemd** (اجرای دائمی و خودکار پس از ری‌استارت سرور)
```bash
sudo cp deploy/vpn-bot.service /etc/systemd/system/vpn-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now vpn-bot
sudo systemctl status vpn-bot
```
> اگر پروژه را در مسیری غیر از `/opt/vpn-bot` قرار داده‌اید، قبل از کپی، مسیرها و `User` را در فایل `deploy/vpn-bot.service` اصلاح کنید.

## 🖥 اجرا با screen یا tmux (بدون systemd)

روش پیشنهادی systemd است (اجرای خودکار پس از خطا یا ری‌استارت سرور)، اما در صورت نیاز:

**screen**
```bash
sudo apt install -y screen
screen -S vpnbot
cd /opt/vpn-bot && sudo .venv/bin/python -m bot
# جدا شدن از صفحه:  Ctrl + A  سپس  D
# بازگشت:           screen -r vpnbot
```

**tmux**
```bash
sudo apt install -y tmux
tmux new -s vpnbot
cd /opt/vpn-bot && sudo .venv/bin/python -m bot
# جدا شدن:  Ctrl + B  سپس  D
# بازگشت:   tmux attach -t vpnbot
```

## 🔧 مدیریت سرویس و به‌روزرسانی

| کار | دستور |
|---|---|
| وضعیت ربات | `sudo systemctl status vpn-bot` |
| مشاهده زنده لاگ | `sudo journalctl -u vpn-bot -f` |
| فایل لاگ | `tail -f /opt/vpn-bot/logs/bot.log` |
| ری‌استارت | `sudo systemctl restart vpn-bot` |
| توقف / اجرا | `sudo systemctl stop vpn-bot` / `sudo systemctl start vpn-bot` |

اسکریپت به‌روزرسانی قبل از هر کاری یک بکاپ از دیتابیس می‌گیرد، سپس آخرین نسخه را از گیت دریافت، کتابخانه‌ها را به‌روز و ربات را ری‌استارت می‌کند.

## 📖 راهنمای شروع کار با ربات

پس از نصب، در تلگرام به ربات `/start` بدهید و روی **«⚙️ پنل مدیریت»** بزنید:

1. **💳 تنظیمات پرداخت** ← شماره کارت، نام صاحب کارت و بانک را وارد کنید (یا لینک پرداخت را تنظیم و فعال کنید).
2. **🖥 سرورها و کانفیگ‌ها** ← «➕ افزودن سرور» و انتخاب نوع سرور ([راهنمای اتصال پنل‌ها](#-اتصال-به-پنلها)).
3. **📦 پلن‌ها** ← «➕ افزودن پلن»: نام، مدت (روز)، حجم (گیگابایت، ۰ = نامحدود)، قیمت (تومان) و توضیحات.
4. اگر سرور «دستی» است: در صفحه پلن، «📦 انبار کانفیگ این پلن» ← کانفیگ‌ها را اضافه کنید.
5. با یک حساب دیگر تلگرام یک خرید آزمایشی انجام دهید.

### روند یک سفارش

```text
کاربر: انتخاب پلن ← انتخاب روش پرداخت ← واریز ← ارسال رسید
                                                   ↓
ادمین: پیام سفارش + تصویر رسید  ←  ✅ تایید  یا  ❌ رد (با دلیل)
                                                   ↓
ربات:  ساخت خودکار کاربر روی پنل / برداشتن کانفیگ از انبار ← ارسال کانفیگ + لینک ساب + QR به کاربر
```

- اگر ساخت خودکار ناموفق باشد (مثلاً پنل در دسترس نیست)، سفارش «تایید شده» باقی می‌ماند و ادمین سه گزینه دارد: **🔄 تلاش مجدد**، **✍️ ارسال دستی کانفیگ** و (برای تمدید) **📅 فقط تمدید تاریخ**.
- سفارش‌هایی که ۲۴ ساعت بدون پرداخت بمانند خودکار لغو می‌شوند.

## 🔌 اتصال به پنل‌ها

### 🟦 پنل 3x-ui (سنایی) — نسخه ۲ و ۳

ربات نسخه پنل را خودکار تشخیص می‌دهد (API قدیمی نسخه ۲.x/۳.۰ و API جدید کلاینت‌ها از نسخه ۳.۱ به بعد، همراه با CSRF).

| فیلد | توضیح |
|---|---|
| آدرس پنل | آدرس کامل **همراه با مسیر مخفی (Web Base Path)**؛ می‌توانید مستقیماً از نوار مرورگر کپی کنید. مثال: `https://panel.example.com:2053/AbCd12` |
| نام کاربری / رمز | اطلاعات ورود ادمین پنل. رمز پس از دریافت از چت حذف می‌شود |
| اینباندها | آیدی اینباند(ها)؛ پس از تست اتصال، لیست اینباندها نمایش داده می‌شود. چند اینباند: `1,3` |
| آدرس ساب (اختیاری) | آدرس پایه ساب‌اسکریپشن پنل، مثال: `https://sub.example.com:2096/sub` — شناسه ساب کاربر به انتهای آن اضافه می‌شود (یا از `{sub_id}` در آدرس استفاده کنید) |
| توکن API (اختیاری) | در نسخه ۳: `Settings → Security → API Token`. اگر ورود دومرحله‌ای (2FA) فعال است از این گزینه استفاده کنید |
| آدرس عمومی (اختیاری) | اگر ربات با آدرس داخلی (مثل `http://127.0.0.1:2053/path`) به پنل وصل می‌شود، دامنه/IP عمومی را اینجا وارد کنید تا در لینک‌ها قرار بگیرد |

- پروتکل‌های پشتیبانی‌شده برای ساخت خودکار: **VLESS** (از جمله Reality و XTLS-Vision)، **VMess** و **Trojan** روی شبکه‌های tcp، ws، grpc، httpupgrade و xhttp.
- برای هر خرید یک کلاینت با حجم و تاریخ انقضای پلن ساخته می‌شود؛ تمدید، تاریخ و حجم را به‌روز و مصرف را صفر می‌کند.
- اگر کلاینت یک سرویس از پنل حذف شده باشد، هنگام تمدید دوباره ساخته می‌شود.

### 🟪 پنل Marzban / PasarGuard

| فیلد | توضیح |
|---|---|
| آدرس پنل | مثال: `https://panel.example.com:8000` |
| نام کاربری / رمز | اطلاعات ادمین پنل (ترجیحاً sudo admin) |
| اینباندها (اختیاری) | **Marzban**: تگ اینباندها با کاما (خالی = همه) — **PasarGuard**: آیدی گروه‌ها با کاما (خالی = همه گروه‌های فعال) |

لینک ساب‌اسکریپشن و کانفیگ‌ها مستقیماً از خود پنل دریافت می‌شوند. نوع پنل (Marzban یا PasarGuard) خودکار تشخیص داده می‌شود.

### 📝 سرور دستی (انبار کانفیگ)

برای وقتی که پنل ندارید یا نمی‌خواهید ربات به پنل وصل شود:
- کانفیگ‌ها را در هر پنلی بسازید و در ربات وارد کنید؛ **هر خط یک کانفیگ** (یا یک فایل `.txt`).
- هر کانفیگ فقط به یک خریدار تحویل داده می‌شود و موارد تکراری خودکار حذف می‌شوند.
- پلن بدون موجودی برای کاربران «ناموجود» نمایش داده می‌شود.
- در تمدید، یک کانفیگ جدید از انبار تحویل داده می‌شود (یا ادمین می‌تواند فقط تاریخ را تمدید کند).

## 💾 بکاپ و ریستور

**بکاپ خودکار:** هر روز دقیقاً ساعت **۰۰:۰۰** (قابل تغییر با `BACKUP_TIME`) به وقت **تهران** (قابل تغییر با `TIMEZONE`)، یک فایل zip از دیتابیس ساخته و **برای همه ادمین‌ها ارسال** می‌شود. آخرین ۱۴ فایل (قابل تغییر با `BACKUP_KEEP`) در پوشه `backups/` سرور هم نگه داشته می‌شود.

**بکاپ دستی:** دستور `/backup` یا دکمه «💾 دریافت بکاپ فوری» در پنل مدیریت.

**ریستور از داخل ربات:**
1. دستور `/restore` را بفرستید (یا «♻️ ریستور از فایل بکاپ»).
2. فایل بکاپ (`backup_....zip`) را به صورت **فایل** ارسال کنید.
3. ربات فایل را بررسی (سالم بودن و تعلق به همین ربات) و خلاصه آن را نمایش می‌دهد؛ پس از تایید، دیتابیس جایگزین می‌شود.
4. قبل از ریستور، یک بکاپ ایمنی (`pre_restore_....zip`) از وضعیت فعلی گرفته می‌شود. نیازی به ری‌استارت نیست.

**بکاپ و ریستور در سرور (خط فرمان):**
```bash
cd /opt/vpn-bot
sudo .venv/bin/python -m bot --backup                      # ساخت بکاپ در backups/
sudo systemctl stop vpn-bot
sudo .venv/bin/python -m bot --restore backups/backup_2026-01-01_00-00-00.zip
sudo systemctl start vpn-bot
```

**انتقال ربات به سرور جدید:** ربات را روی سرور جدید نصب کنید (با همان توکن)، سپس با `/restore` آخرین فایل بکاپ را بفرستید.

> ℹ️ فایل `.env` (توکن و آیدی ادمین) داخل بکاپ نیست؛ یک نسخه از آن را جداگانه نگه دارید.
> ℹ️ محدودیت تلگرام برای دانلود فایل توسط ربات ۲۰ مگابایت است؛ برای بکاپ‌های بزرگ‌تر از ریستور خط فرمان استفاده کنید.

## 🧾 تنظیمات فایل `.env`

این فایل در اولین اجرا خودکار ساخته می‌شود. پس از هر تغییر، ربات را ری‌استارت کنید: `sudo systemctl restart vpn-bot`

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات از @BotFather (اجباری) |
| `ADMIN_ID` | — | آیدی عددی مالک (اجباری). برای چند ادمین با کاما جدا کنید: `111,222` |
| `TIMEZONE` | `Asia/Tehran` | منطقه زمانی بکاپ خودکار، تاریخ‌ها و لاگ‌ها |
| `BACKUP_TIME` | `00:00` | ساعت بکاپ خودکار روزانه (HH:MM) |
| `BACKUP_KEEP` | `14` | تعداد بکاپ‌های نگه‌داشته‌شده روی سرور |
| `DB_PATH` | `data/bot.db` | مسیر فایل دیتابیس |
| `BACKUP_DIR` | `backups` | پوشه بکاپ‌ها |
| `LOG_DIR` | `logs` | پوشه لاگ‌ها |
| `LOG_LEVEL` | `INFO` | سطح لاگ: `DEBUG`، `INFO`، `WARNING`، `ERROR` |
| `PROXY_URL` | — | پروکسی اتصال به تلگرام، مثال: `socks5://127.0.0.1:1080` یا `http://user:pass@host:port` |
| `PANEL_VERIFY_SSL` | `false` | بررسی گواهی SSL پنل‌ها (برای پنل با IP یا گواهی self-signed مقدار `false` بماند) |

## ❓ عیب‌یابی

<details>
<summary><b>ربات جواب نمی‌دهد</b></summary>

1. وضعیت سرویس: `sudo systemctl status vpn-bot`
2. لاگ‌ها: `sudo journalctl -u vpn-bot -n 100 --no-pager` یا `tail -n 100 /opt/vpn-bot/logs/bot.log`
3. تنظیمات: `sudo /opt/vpn-bot/.venv/bin/python -m bot --check`
4. مطمئن شوید ربات دیگری (یا نسخه دیگری از همین ربات) با همین توکن اجرا نمی‌شود.
</details>

<details>
<summary><b>خطای «اتصال به سرورهای تلگرام برقرار نشد»</b></summary>

سرور به `api.telegram.org` دسترسی ندارد (معمولاً سرورهای داخل ایران). یک پروکسی SOCKS5/HTTP در `PROXY_URL` فایل `.env` تنظیم و ربات را ری‌استارت کنید.
</details>

<details>
<summary><b>خطای «توکن ربات نامعتبر است»</b></summary>

توکن را با `sudo .venv/bin/python -m bot --setup` دوباره وارد و ربات را ری‌استارت کنید. (در این حالت systemd ربات را خودکار ری‌استارت نمی‌کند تا لاگ پر نشود.)
</details>

<details>
<summary><b>ادمین پیام «ربات روشن شد» یا فایل بکاپ را دریافت نمی‌کند</b></summary>

ادمین باید حداقل یک بار به ربات `/start` داده باشد و آیدی عددی در `ADMIN_ID` درست باشد (با دستور `/id` در ربات می‌توانید آیدی خود را ببینید).
</details>

<details>
<summary><b>اتصال به پنل 3x-ui ناموفق است</b></summary>

- آدرس باید **همراه با مسیر مخفی پنل** باشد (همان آدرسی که در مرورگر باز می‌کنید).
- اگر ورود دومرحله‌ای فعال است، در نسخه ۳ از «توکن API» استفاده کنید.
- برای پنل با گواهی self-signed یا IP، `PANEL_VERIFY_SSL=false` باشد.
- فایروال سرور پنل باید اجازه اتصال از سرور ربات را بدهد.
- از دکمه «🧪 تست اتصال» در صفحه سرور برای دیدن پیام دقیق خطا استفاده کنید.
</details>

<details>
<summary><b>آدرس سرور در لینک‌های تحویلی اشتباه است</b></summary>

در صفحه سرور، فیلد «📍 آدرس عمومی» را روی دامنه/IP عمومی تنظیم کنید، یا «🔗 آدرس ساب» را وارد کنید تا لینک‌ها مستقیماً از ساب‌اسکریپشن پنل گرفته شوند.
</details>

## 🔐 نکات امنیتی

- فایل `.env` حاوی توکن ربات است؛ آن را با کسی به اشتراک نگذارید (دسترسی فایل خودکار `600` تنظیم می‌شود).
- دیتابیس و فایل‌های بکاپ شامل رمز پنل‌ها و اطلاعات مشتریان هستند؛ بکاپ‌ها فقط برای ادمین‌ها ارسال می‌شوند.
- اگر توکن ربات لو رفت، فوراً در @BotFather با دستور `/revoke` توکن جدید بگیرید و با `--setup` جایگزین کنید.
- پنل مدیریت فقط برای آیدی‌های عددی موجود در `ADMIN_ID` در دسترس است.
- سیستم‌عامل سرور را به‌روز نگه دارید: `sudo apt update && sudo apt upgrade`
